## Node.js v24.22.3 (downloaded at runtime; not included in this bundle)

When no compatible system Node.js is found, the plugin downloads the official Windows x64 release ZIP from <https://nodejs.org/dist/v24.22.3/node-v24.22.3-win-x64.zip>. It verifies the archive against `SHASUMS256.txt` (SHA-256 `e612af99f626ab415ea225af6bce5c971feb448cb5cae250bb1c3fa50c5f7d9f`) and also checks the extracted `win-x64/node.exe` hash (`86fc4785327db5f5c7558dc6156c543b433c313e813a222e088086222ab4afa6`). The official release `LICENSE` is extracted beside the private runtime binary under the user's LocalAppData. The Node.js project license and included third-party notices are available at <https://github.com/nodejs/node/blob/v24.22.3/LICENSE>.

The Node.js executable is not redistributed inside this plugin package; it is fetched directly from nodejs.org at first use. The version and hashes are intentionally pinned in the plugin source and must be updated together from a reviewed official release manifest.
