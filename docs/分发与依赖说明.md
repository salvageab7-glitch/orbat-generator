# 分发与依赖说明（v0.3.6）

回答一个问题：**现在软件工作流的依赖，普通 Windows 用户哪些一般都有、哪些没有？**

## 结论速览

| 依赖 | 普通用户有没有 | 影响 | 怎么办 |
|---|---|---|---|
| Windows 10/11 | ✅ 基本都有 | GUI 运行 | 无需处理 |
| Edge 浏览器 | ✅ Win10/11 自带 | **出图必需** | 无需处理（Edge 在探测列表里） |
| 网络访问 | ✅ 一般有 | 识图 + 出图必需 | 需能访问 deepseek.com 和 spatialillusions.com |
| **Node.js ≥ 24** | ❌ **通常没有** | **出图必需** | **必须安装，这是最大门槛** |
| API Key | ❌ 没有 | 识图必需 | 申请 DeepSeek key，用环境变量或设置里填 |
| Dart SDK | ❌ 没有 | **已不再是依赖** | P2-2 后 CLI 用独立 exe，GUI 是编译产物，都不需要 |
| `runtime\` 脚本目录 | — | 出图必需 | 随包分发（交付目录已含） |
| `data\` 资源目录 | — | GUI 必需 | 随包分发（交付目录已含） |

**一句话**：分发后用户唯一需要自己装的第三方软件是 **Node.js ≥ 24**，
外加申请一个 API Key。浏览器和 Dart 都不是问题。

## 为什么 Node.js 是必需且版本卡得死

出图流程：`orbat-cli.exe render` → 启动 Node 脚本 `runtime/render_orbat.js` →
Node 用 CDP 协议控制 Edge/Chrome 打开 spatialillusions.com → 导入 JSON → 截图导出 PNG/SVG。

代码中有一道**硬性版本守卫**（`render_orbat.js` 开头）：

```js
if (Number(process.versions.node.split(".")[0]) < 24) {
  console.error("FATAL: 出图必须用 node ≥ 24，当前是 v" + process.versions.node);
}
```

原因：managed node v22 跑这个脚本会**无界挂起**（画布渲染完了，但 `SVG_STAT` 之后再无输出）。
所以低于 24 会直接拒绝，而不是卡死。分发时必须注明"需 Node.js 24 或更高"。

Node.js 安装很简单：官网下载 LTS 安装包一路下一步即可，普通用户能搞定。

## 各功能的依赖矩阵

按命令拆开看，哪些离线可用、哪些要联网、哪些要 Node：

| 命令 | Node.js | 浏览器 | 网络 | API Key |
|---|---|---|---|---|
| `parse`（解析） | ❌ 不需要 | ❌ | ❌ 离线 | ❌ |
| `validate`（校验） | ❌ | ❌ | ❌ | ❌ |
| `normalize`（归一化） | ❌ | ❌ | ❌ | ❌ |
| `config` / `usage` | ❌ | ❌ | ❌ | ❌ |
| `retry-tile`（裁块） | ❌ | ❌ | ❌ | ❌ |
| `selfcheck`（自检） | ❌ | ❌ | ✅ 测连通 | ❌ |
| `render`（出图） | ✅ 需要 | ✅ | ✅ | ❌ |
| `generate`（识图） | ❌ | ❌ | ✅ | ✅ |
| `batch`（批量） | ✅ | ✅ | ✅ | ✅ |

**含义**：接收方即使没装 Node.js，也能用 CLI 做 JSON 解析/校验/归一化这些本地活；
只有到"出图"那一步才需要 Node + 浏览器。

## 分发最小清单

给别人时，压缩这些即可（约 38MB）：

```
编制生成器v0.3.6\
├── 启动.exe          GUI 入口，双击即用
├── orbat-cli.exe     CLI 入口，Agent 调用
├── flutter_windows.dll
├── data\             GUI 资源（不可删）
├── runtime\          渲染脚本（不可删，出图必需）
├── CLI说明.md
├── 版本记录.md
└── 分发与依赖说明.md  （本文件）
```

**不要带**（都是本机运行记录，含隐私且让包变大）：
`orbat-logs\`、`orbat-snapshots\`、`usage.jsonl`、`browser-*.log`、`orbat-render-*` 临时目录。

**可选带**：`orbat.bat` + `cli\`（Dart 源码备用入口）。给别人可以去掉——
他们用 `orbat-cli.exe` 就够了，不需要 Dart SDK。

## 首次使用引导（给别人时一句话说清）

1. 装 Node.js 24+（官网 LTS 安装包）
2. 申请 DeepSeek API Key
3. 设环境变量 `DEEPSEEK_API_KEY=sk-你的key`
4. 双击 `启动.exe` 用 GUI；或命令行 `orbat-cli.exe selfcheck` 确认环境 OK

`selfcheck` 会逐项列出 Node/浏览器/脚本路径/API Key/网络的状态和修复建议，
是排查环境问题的第一入口。

## 本机（开发者）与分发版的差异

本机开发时不需装 Node 也有——因为已经有 `C:\Program Files\nodejs\node.exe`（v24+）。
分发给别人时，这一步是唯一需要对方动手的地方。

Dart SDK 曾经也是依赖（旧 `orbat.bat` 走 `dart run`），P2-2 后已解除：
`orbat-cli.exe` 是 AOT 原生程序，运行不需要任何 Dart 环境。
