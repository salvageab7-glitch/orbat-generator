# v0.3.4-beta 更新说明

> 对比上一公开版 v0.3.0-beta。本次是累积更新：识图修复 → 产物目录与复制 → 正确率改造 → 英文界面与单位编辑。

## 一、识图正确率

- **分块识图边界修复**：同一单位被切到两块时不再识别成两份；块根与总根同级时只并入子节点，避免出现两个并列的师
- **名称 ↔ 军标码一致性审计**：模型给的 30 位码与名称层级/兵种不一致时，按名称裁决并记录（如「第2炮兵营」给了连级码，自动纠正为营级）
- **校验器补齐四类结构检查**：同父同名、名称互为前缀、层级倒挂、空中单位用陆地符号集
- **补丁式修复**：修复环节只发问题节点，模型返回 `path + 新值`，程序按路径应用——不再把整棵树交给模型重写（历史事故：176 节点只回 32 个）
- **跨父节点同名合并**：分块时同一单位挂到两个父节点下会被自动并回一份

## 二、提示词

- 外文层级词表（Division/Brigade/Regiment… Корпус 等），外文图不再靠模型自由翻译
- 方框计数锚：观察段报「方框 N」，自检段报「节点核对 M/N」，程序可验证
- 层级判据声明（连线/缩进/纵向包含），非标准画法不再自由发挥
- 注释收紧：**12 个汉字 / 20 个字母**，只写驻地或职能短名，不写指挥官姓名

## 三、产物与出图

- 默认输出到 `软件目录\输出文件存档\`（不再往桌面根目录扔）
- 「复制 PNG」一键进剪贴板（同时写位图/文件/PNG 三种格式，粘到微信或 Word 都对）
- 「打开存档目录」直接跳到产物文件夹
- **导出 JSON 保真**：不再把长单位名截断（只在送渲染器时做长度适配）
- 出图仍走线上渲染器（spatialillusions.com），未引入本地渲染回退

## 四、自检与诊断

- 自检新增「出图冒烟」：内置 3 节点固定用例真渲染一次，20 秒内确认这台机器能不能出图
- **首次启动自动跑一次自检**（含冒烟），之后可手动触发
- API 错误全部入日志：状态码、响应片段、耗时、第几次尝试；401/402/403 不再无意义重试
- 配置读写失败也会留痕（受控环境写不进 AppData 时，曾表现为"设置改完重启又变回去"）

## 五、界面与交互

- **中英切换**：设置 → 界面语言 → 跟随系统 / 中文 / English，全界面生效
- **单位编辑**：树视图每行「编辑」按钮，或 JSON 面板「按单位编辑」；可改名称、注释、SIDC，注释长度实时提示
- 工具栏窄窗口自适应（按钮收成图标，不再被窗口边缘裁切）

## 六、命令行（`orbat-cli.exe`）

| 命令 | 说明 |
|---|---|
| `generate --image/--text` | 生成编制 JSON（`--raw-names` 保留原文称号/番号） |
| `validate` | 校验，红牌时 exit=3 |
| `audit` | 一致性审计 + 跨父同名扫描（只读） |
| `edit --path … --name/--note/--sidc` | 按路径改单位（也支持 `--patches` 批量） |
| `render` | 出图（PNG + SVG） |
| `batch` | 目录批量识图 + 出图 |
| `selfcheck --smoke` | 环境检查 + 真渲染冒烟 |

产物宣告：所有命令返回 `outputDir` 绝对路径；无输入上下文时兜底到 `orbat-cli.exe 同级\输出文件存档\`。

## 七、已知限制

- 识图质量依赖原图清晰度；超大图会自动切片
- 出图必须联网（线上渲染器），站点不可用时出图失败但识图/校验仍可用
- 未签名程序，首次运行会有 SmartScreen 提示
- 界面语言切换暂不影响窗口标题栏
