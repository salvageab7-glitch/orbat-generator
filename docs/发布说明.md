# 编制生成器 v0.3.4-beta 公开测试版

从编制结构图（组织架构图/军旗标图）自动识别生成标准 JSON，再用军标符号渲染出图。
支持三种用法：软件界面识图 / 命令行识图 / AI Agent 用提示词自行转写。

---

## 本版新增（0.3.4）

- **英文界面**：设置里可切「跟随系统 / 中文 / English」，全界面（含自检、批量、编辑对话框）随语言切换
- **直接改单位**：树视图每行有「编辑」按钮，JSON 面板有「按单位编辑」，可改名称、注释、SIDC
- **命令行补齐**：`audit`（一致性审计）、`edit`（按路径改单位）、`selfcheck --smoke`（真渲染自检）

## 0.3.3 新增

- **全中文输出开关**（底部默认勾选）：勾选=名称注释译成中文；取消=保留原文称号/番号/注释
- **注释收紧**：只写驻地或职能短名，12 个汉字（英文 20 字母）以内，不写指挥官姓名
- **出图自检**：首次启动自动跑一次真渲染，20 秒内告诉你"这台机器现在能不能出图"
- **名称与军标码自动对齐**：AI 给的码与名称不一致时，按名称修正并记入日志
- **导出的 JSON 不再被截断**：以前长单位名会被压到 26 字，现在导出即原文

## 0.3.2 新增

- **产物默认落在软件自己的文件夹**：`软件目录\输出文件存档\`，不再往桌面根目录乱扔
  （可在界面「更改目录」里改到别处）
- **一键复制出图**：出图后点「复制 PNG」，直接粘到微信 / QQ / Word 就是图片
- **一键打开存档目录**：不用再去资源管理器里翻路径
- 识图修复（0.3.1 起）：分块识图不再把同一个旅识别成两份、不再残留 `[?]` 占位符

## 〇、三种发布形态（按需选择一种下载）

| 形态 | 体积 | 适合谁 | 安装后还要做什么 |
|---|---|---|---|
| **完整版 Setup**（单个 exe 安装器） | 约 60 MB | 想装完即用的用户 | **几乎不用**：已内置 Node.js，会自动补 VC++ 运行库；只需申请 DeepSeek Key |
| **精简版 Setup**（单个 exe 安装器） | 约 13 MB | 磁盘/流量紧张的用户 | 自装 Node.js ≥ 24（nodejs.org）；向导里有提醒 |
| **zip 便携版**（解压即用，不写注册表） | 约 16 MB | 免安装/U 盘场景 | 自装 Node.js ≥ 24；首次运行过 SmartScreen |

> 三种形态装的是同一个软件。完整版与精简版互为覆盖升级（同一安装 ID）。

## 一、快速开始（3 步，对应 zip 便携版）

1. **解压**到任意文件夹（建议不要放在 C:\Program Files，普通目录即可）
2. **安装 Node.js 24 或更高版本**（出图必需，见下方第二节；完整版安装器已内置，可跳过）
3. 双击 `启动.exe`，在右上角设置里填入 DeepSeek API Key（识图必需，见第三节）

首次双击 `启动.exe` 时，Windows 可能弹出蓝色提示"Windows 已保护你的电脑"。
这是对未签名程序的正常提示，不是病毒：点 **更多信息 → 仍要运行** 即可。

## 二、安装 Node.js（出图必需，一次性）

- 到 https://nodejs.org 下载 **LTS 安装包**（需要 24 或更高版本），一路下一步安装
- 装完后重启本软件即可出图
- **完整版安装器已随包内置 node.exe，装完即可出图，无需此步**
- 不装也能用识图和校验功能，只是无法渲染出图

## 三、申请并填写 DeepSeek API Key（识图必需）

1. 到 https://platform.deepseek.com 注册账号
2. 在「API Keys」页面创建一个 Key（形如 `sk-` 开头的长字符串）
3. 双击 `启动.exe` → 右上角设置 → 粘贴 Key → 保存
- Key 只保存在你自己电脑的 `%APPDATA%\OrbatGenerator\config.json`，不会上传到任何第三方
- 也可以用环境变量 `DEEPSEEK_API_KEY` 传给命令行

## 四、环境要求

| 依赖 | 说明 |
|---|---|
| Windows 10 / 11 | 64 位 |
| Edge 或 Chrome 浏览器 | Win10/11 自带 Edge，一般无需安装（出图用） |
| Node.js ≥ 24 | 出图必需（见第二节） |
| 网络 | 需能访问 deepseek.com（识图）和 spatialillusions.com（出图） |

## 五、软件里已内置的功能

- **一键自检**：软件内已配置，可验证识图/校验/出图链路是否正常，出图报错时先跑自检
- 识图提示词反臆造自检：每个单位都要求在原图上有对应方框，防止凭空多造层级
- 输出目录自定：默认输出到 `软件目录\输出文件存档\`，可在界面里一键改到任意位置
- 一键复制 / 打开存档目录：出图后「复制 PNG」可直接粘贴到聊天窗口或文档

## 六、命令行（可选，面向高级用户 / AI Agent）

`orbat-cli.exe` 提供 JSON 校验与出图能力，详见随包的《CLI说明.md》。
常用：

```
orbat-cli.exe validate --in 编制.json     # 校验（红牌=必须修，警告=可忽略）
orbat-cli.exe render --in 编制.json --out 输出名
```

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 双击提示"Windows 已保护你的电脑" | 更多信息 → 仍要运行 |
| 出图报"Node.js 未安装或版本过低" | 按第二节安装 Node.js 24+，重启软件 |
| 出图报"缺少浏览器" | 安装 Chrome 或确认 Edge 可用 |
| 识图报网络错误 | 检查能否打开 deepseek.com；公司内网可能需要代理 |
| 程序闪退 | 到 `%APPDATA%\OrbatGenerator\logs\` 查看当天日志 |
