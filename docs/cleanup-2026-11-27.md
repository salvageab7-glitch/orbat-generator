## 5. 恢复与注意事项

1. 第一次运行前：
   ```powershell
   cd app
   C:\flutter\bin\flutter.bat pub get
   ```
2. 需要 Windows Release 时，在 ASCII 路径重建；中文路径只用于 Debug。
3. 需要 CLI 时运行 `app/scripts/build_cli.sh`。
4. 需要插件 `dist/` 时重新构建；源码与 `orbat-cli.exe` 未删除。
5. 归档目录在 `.gitignore` 中，不进入 git；确认无用后可整目录删除。

## 6. 后续清理建议

- 每周清理 `app/build/` 与 `dsh-orbat-plugin/dist/`。
- `app/test/` 新增调试产物统一放 `app/test/_artifacts/`（已 gitignore）。
- 发布快照只保留最近两个版本；旧版本移入 `归档/` 或外部存储。
- 不在根目录新增临时截图/JSON；放 `归档/`。
