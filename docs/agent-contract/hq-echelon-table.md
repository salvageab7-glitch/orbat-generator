# HQ 梯队用码表

> 用途：统一“排部/连部/营部/旅部/师部/军部”SIDC 梯队段（0-based 位 8-9）的写法。
> 来源：项目 `prompt.dart` 的 HQ 规则 + `.agents/skills/orbat-json-writer/reference/us-bct-templates.md`。不同国家军制可能有差异，拿不准时保留来源层级并提问。

## 1. 纯 HQ 分队

| HQ 形态 | 梯队码 | 说明 |
|---|---:|---|
| 排部 | `13` | 比所属排（14）低一级 |
| 连部 | `14` | 比所属连（15）低一级 |
| 营部/营部连（HHC） | `15` | HHC 是连级 |
| 旅部/旅部连（HHT） | `15` | HHT 是连级 |
| 师部/师部连 | `15` | 师直属连级机关 |
| 军部/军部连 | `15` | 军直属连级机关 |
| 中队部连 | `15` | 中队（17）的部连 |

## 2. 合成 HQ（名称含实兵）

| 名称 | 梯队码 | 说明 |
|---|---:|---|
| 旅部及旅部连 | `15` | 含连级实兵 |
| 师部及师部营 | `16` | 含营级实兵，不能机械降成 15 |
| 营部及营部连 | `15` | 含连级实兵 |
| 连部及连部班 | `14` | 含班级实兵 |

## 3. 父子关系注意

- 纯 HQ 允许“子节点梯队低于父节点”（如旅 18 → 旅部连 15）。
- 合成 HQ 按所含实兵取码（师部及师部营 = 16）。
- 不要把“HQ 一律 15”套到所有层级；先判断是否含实兵、实兵规模。

## 4. 待确认

- 军部/战区级 HQ 在不同军制下可能不同；如来源明确写出“军部及军部连”，优先按实兵规模。
- 若未来补更多国家模板，在本表追加行，并同步 `prompt.dart` 与 skill。
